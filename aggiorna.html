🔄 Aggiorna Giacenze

Carica il file Excel da AdHoc, genera il nuovo file e caricalo su GitHub.

1. Seleziona il file Excel

2. Genera e scarica

Adesso carica il file su GitHub:
  1. Vai su github.com/riccini/giacenze-magazzino
  2. Clicca su index.html
  3. Clicca i tre puntini ... → Upload new version
  4. Seleziona il file appena scaricato
  5. Clicca Commit changes

I rappresentanti vedranno i dati aggiornati in 1-2 minuti.
